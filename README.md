# 👋 Welcome to Emil’s Special Repository

This is my little corner of the internet where I gather the projects, ideas, and experiments that keep me up at night (in the best way possible).  
I spend most of my time building with **Laravel**, **Livewire**, and **TailwindCSS** — mixing backend logic with frontend magic ✨.

---

## 🚀 Things I’m Building

- 🏡 [Boligforeningsweb](https://boligforeningsweb.dk) & [Anyhoa](https://anyhoa.com)  
  Platforms for Danish and international homeowners’ associations.  
  Helping communities run smoother, one digital tool at a time.

- 💳 [Alunta](https://alunta.com)  
  A subscription management system for companies that love predictable revenue (and clean invoices).

- 🔞 [IdGuard](https://idguard.dk)  
  A plugin for **age verification** in web shops using Danish MitID.
